THE BATON IS THE LINK

No lobby. No account. No server waiting for both players.

Every obstacle comes from the relay seed. Every handoff carries the bounded run state in the URL fragment, which browsers do not send to a web server. The checksum catches damaged links; it is not an anti-cheat claim.

HOW TO PLAY

Keep the signal alive for ten seconds.

  1. Steer by dragging anywhere, or use arrow/WASD keys.
  2. Collect sparks to build score and combo.
  3. Avoid gates and static mines. Three hits end the chain.
  4. Choose a gift, then pass the generated link to the next runner.

Incoming relay data is validated and size-bounded. It is still player-controlled data, not a trusted leaderboard record.
