# Contributing

Small, evidence-backed changes are welcome.

1. Open an issue describing the player problem or measurable hypothesis.
2. Keep the game dependency-free unless a dependency clearly earns its cost.
3. Preserve touch, pointer, keyboard, reduced-motion, and sound-optional behaviour.
4. Run `npm run check`.
5. State what was tested manually and which devices were not tested.

Please do not add analytics, advertising, accounts, remote assets, or network services
without prior discussion and an explicit privacy/threat-model update.
